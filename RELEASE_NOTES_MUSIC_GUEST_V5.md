# Pardais Party — Music & Guest Controls v5

- Base: Web Test 1.0.8 (Version Code 9)
- Version metadata intentionally unchanged.
- Solo and Video Guest use the same Party Music library UI and state.
- Library, Audius Search, Saved, Add Song, play/pause, stop and volume controls are wired to the existing music controller.
- Solo/Guest music state is synchronized with the Agora Party Audio publisher so selected music is published on the live channel.
- Guest lower area now gives comments full width, with Mic, Camera, Rotate Camera, Music, Gift, Share and Requests in one lower navigation row.
- Guest Camera/Rotate buttons control the existing live camera state and facingMode used by AgoraStream.
- The old Solo/PK bottom control bar is hidden while Video Guest mode is active to prevent duplicate controls.
