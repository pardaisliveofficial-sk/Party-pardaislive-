# Pardais Party View Themes

Implemented a shared Party View / Background picker without changing existing party functionality.

- Added 3-dot Party View button beside Games/Share/Exit.
- Added left-side theme drawer.
- Default Lounge remains the default.
- Added Eid ul Fitr, Eid ul Adha, Milad un Nabi, Islamic Mosque, Pakistan Day, Jungle, Mountain, Desert Night, Club Lounge and Sunset Lake themes.
- Theme changes persist on the party record and are visible to all participants through the existing 3-second party snapshot refresh.
- 12-seat and 25-seat layouts remain unchanged.
- Existing seats, audio, Agora, gifts, comments, games, moderation, invites, mute/lock, share and exit behavior remain unchanged.
