# Pardais Party 1.0.6

## Release
- Version Name: 1.0.6
- Android Version Code: 7
- Previous Play Store release: 1.0.5 (Version Code 6)

## Music Update
- Audius music search integration
- Play Audius tracks through the Pardais Party music flow
- Save/Pin songs to a user-specific Saved Songs list
- Saved songs persist with the user account
- Backend keeps Audius credentials server-side through Railway environment variables
- Existing Party/Agora audio flow remains in place

## Compatibility
- Existing app features and user data are preserved; this is an additive update.
