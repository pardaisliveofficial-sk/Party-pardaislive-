Install Pardais Party

iPhone par Pardais Party ko Safari se Home Screen par app ki tarah add karein.

1
Safari mein ye page open rakhein.
Chrome nahi — iPhone par Safari use karein.
2
Neeche ya upar Share button □↑ dabayein.
3
Share menu mein Add to Home Screen select karein.
4
Add dabayein. Pardais Party ka original icon Home Screen par aa jayega.
Open Pardais Party

Button se asli Pardais Party website khulegi. Phir Safari ke Share menu se Add to Home Screen karein.
