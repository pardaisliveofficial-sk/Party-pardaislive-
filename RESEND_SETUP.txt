Pardais Party Resend configuration

Use the verified Resend sending domain:
mail.pardaisparty.soulverseapps.com

Recommended Railway variables:
RESEND_API_KEY=<your existing Resend API key>
RESEND_FROM_EMAIL=noreply@mail.pardaisparty.soulverseapps.com
RESEND_FROM_NAME=Pardais Party

The server also defaults to noreply@mail.pardaisparty.soulverseapps.com if RESEND_FROM_EMAIL is not set.
Do not use onboarding@resend.dev for production OTP delivery.
