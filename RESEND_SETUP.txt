Pardais Party production OTP setup

Set these variables in Railway for the backend:

RESEND_API_KEY=<your Resend API key>
RESEND_FROM_EMAIL=<an email address on a domain verified in Resend>
RESEND_FROM_NAME=Pardais Party

Important:
- Do not use onboarding@resend.dev for sending OTPs to arbitrary users. It is only suitable for Resend's testing/restricted flow.
- Verify the sending domain in Resend first, then use an address such as no-reply@your-verified-domain.

Video upload fix included:
- Removed the old 3-second R2 upload timeout.
- Production R2 upload now allows up to 10 minutes for larger mobile videos.
- OTP delivery uses the Resend HTTPS API and reports delivery failures correctly.
