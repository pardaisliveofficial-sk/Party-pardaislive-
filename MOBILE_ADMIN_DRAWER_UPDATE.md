# Mobile Admin Drawer Update

- Added responsive off-canvas admin navigation for phones.
- Desktop sidebar remains visible and unchanged at md+ breakpoints.
- Mobile gets a top-left menu button in the admin header.
- Tapping the menu opens a full-height navigation drawer with a close X.
- A backdrop closes the drawer when tapped outside.
- Selecting any admin section automatically closes the drawer.
- Main admin content becomes full-width with tighter mobile padding.
- Header status text is truncated on narrow screens and secondary status controls are hidden below the small-screen breakpoint.
