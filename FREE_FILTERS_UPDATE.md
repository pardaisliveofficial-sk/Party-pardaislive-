# Free Beauty & AR Filters Update

Added a zero-cost, render-only filter layer for the live host view. It does not modify the Agora camera track, camera device selection, publishing, or video element CSS, specifically to avoid Android black-screen regressions.

Included filters:
- Natural Beauty
- Soft Glow
- Fresh Skin
- Cat
- Bunny
- Dog
- Devil Horns
- Crown
- Cool Glasses
- Hearts
- Flower Crown
- Sparkle
- Alien

These are built with native React/CSS/emoji rendering and require no paid SDK, API key, subscription, or per-user fee.
