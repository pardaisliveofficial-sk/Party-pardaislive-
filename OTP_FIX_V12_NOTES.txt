PARDAIS PARTY — OTP VERIFICATION V12

Only the OTP verification flow was changed.

Fixes:
1. /api/v1/auth/verify-email-otp now validates the hot OTP and sends the signed
   session response before any Firestore persistence is awaited.
2. Firestore/user persistence runs after the HTTP response in the background.
3. Added /api/v1/auth/recover-email-session for a dropped/proxy-lost response.
4. The web auth gate retries through the recovery endpoint if the first verify
   response is lost.
5. The React OTP flow uses the same real verification endpoint and recovery path.
6. Removed the fake OTP fallback from the React OTP flow.

IMPORTANT DEPLOYMENT:
The ZIP must be deployed with the backend (server.ts) as well as the frontend.
The web gate calls https://api.pardaisparty.soulverseapps.com, so that API must
run this V12 server code. Deploying only static frontend files will not change
that API's verification behavior.
