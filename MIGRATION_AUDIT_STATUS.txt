Pardais Party migration progress — 20 Nov 2026
================================================

OVERALL STATUS: IN PROGRESS — NOT A PRODUCTION RELEASE.

STAGE 1 — SIGNUP / LOGIN
------------------------
Implemented in the Pardais Party codebase:
- Existing Pardais email signup OTP flow retained.
- Existing Pardais email/username + password login retained.
- Existing Google sign-in flow retained.
- Existing forgot-password / reset-password OTP flow retained.
- Added Pardais-owned email OTP login endpoints:
  POST /api/v1/auth/send-login-otp
  POST /api/v1/auth/verify-login-otp
- Added client helpers and Login UI mode toggle (Password / Email OTP).
- Signup and login OTP challenges have distinct type checks so one flow's
  challenge cannot be consumed by the other.
- Login OTP sends a generic response for unknown/ineligible accounts to reduce
  account-enumeration risk.
- Alpha Mate Firebase Auth is not used by Pardais login. Pardais API/session and
  Pardais database remain authoritative.

- Added dedicated Party Rooms view using Pardais Party's existing party records.

  Home → Rooms → Store → Plus → Videos → Chat → Profile
- Store maps to the existing Shop screen.
- Videos maps to the existing Moments feed.
- Plus retains the existing create/stream action sheet.
- Removed obsolete Live tab from bottom navigation; live functionality remains
  reachable from the existing Home/Live controls and create/stream actions.
