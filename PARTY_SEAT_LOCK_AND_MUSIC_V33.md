# Pardais Party V33 — Seat Lock + Background Music

## Seat Lock
- Host can tap any non-host seat and choose **Lock Seat / Unlock Seat**.
- Locked seats show a lock badge.
- Guests cannot directly occupy a locked seat; the existing request flow remains available.
- Host can quickly lock/unlock all currently empty guest seats.
- Server now enforces that only the Host can change seat locks.
- Server now enforces locked-seat checks and prevents direct API bypass.
- Host seat #1 cannot be locked.

## Party Music Library
- A **Music** button is available to the Host or a seated speaker.
- Searchable, scrollable Pardais music library.
- Select, play, pause, stop and change music volume.
- Background music is published as a separate Agora audio source so live microphone voices continue simultaneously.
- Music automatically stops when leaving the party room.
- Existing party mic, gift, game, moderation and room controls remain unchanged.
